# Orphaned Well Map

An interactive map of the **130,121 unplugged orphaned oil and gas wells in 28 states** in the
USGS *United States Documented Orphaned Well Database 2026*
([doi:10.5066/P13FHBYG](https://doi.org/10.5066/P13FHBYG)). The USGS file has no operator data, so
the pipeline joins each well to state well records to show:

- **the last operator of record**, the company that held the well before it was orphaned
- **active wells nearby** (default: within 1 mile), with their operators and lease names

The site also ranks operators by how many orphaned wells they last operated, which is the
lead-story angle.

## Layout

```
pipeline/owm/        Python (stdlib only): load USGS file, load state files, join, write JSON
pipeline/states/     one JSON config per state describing its well-record file (see README there)
site/                static site: MapLibre GL map, no build step
site/data/           generated by the pipeline (not committed)
tests/               pytest, with synthetic fixtures
```

## Run it

The USGS table comes from the public DOWDB API (`https://energy.usgs.gov/api/dowdb/v1/wells`,
PostgREST, CSV via `Accept: text/csv`); see the paging loop in `.github/workflows/site.yml`.
The same data is on ScienceBase as `US_orphaned_wells_2026.csv`.

```sh
cd pipeline
python -m owm.build --inspect /path/to/usgs.csv      # check the detected columns
python -m owm.build --usgs /path/to/usgs.csv         # writes ../site/data
# state files you downloaded by hand:
python -m owm.build --usgs usgs.csv --state-file PA=pa_wells.csv --state-file OH=oh_wells.csv

cd ../site && python -m http.server 8000             # http://localhost:8000
pytest -q tests                                       # from the repo root
```

Without any state configs the map still works: every well shows its USGS location and
attributes, colored "state not joined yet."

## Deploy

`.github/workflows/site.yml` runs the tests, downloads the USGS table and every configured state
file, builds the data, and on `main` deploys to GitHub Pages (set Settings → Pages → Source to
"GitHub Actions"). `.github/workflows/fetch-data.yml` downloads the files listed in
`data/fetch.tsv` into a draft release named `source-data`, for inspecting sources from an
environment that can't reach the agency sites.

A separate layer (124,599 wells) of wells that aren't orphans yet because the state still names an

Each state's rule is its config's `at_risk` block; counts are in the table above.

Operator names are grouped across states with common agency abbreviations expanded (PROD → production,
OPR → operating, DEV → development), so e.g. "DIVERSIFIED PROD LLC" and "DIVERSIFIED PRODUCTION LLC" count together.

## Land ownership view

From USGS's own estimates (BLM Surface Management Agency map): federal surface (12,369 wells, 9,578 of
them national forest), federal minerals under non-federal surface (617, mapped only in NM, CO, ND, UT),
state/local/tribal (2,641), confirmed private (2,844), and not determined (111,650). "Not determined" is
mostly non-federal land the map doesn't classify; it is not a count of private wells.

## How the join works and where it can go wrong

1. **API match.** USGS and state API numbers are reduced to 10 digits (state + county + well).
   Dashes, 12/14-digit suffixes, a leading zero dropped by Excel, and state files that omit
   the state prefix are all handled.
2. **Location fallback.** For wells with no usable API, the nearest state record within 30 m is
   used and shown as a weaker "location match."
3. **Last operator.** When an API appears on several rows, the latest row naming a real company
   wins. Rows saying "Unknown," "Orphan Well Program," "State of …" and similar are flagged as
   placeholders, not treated as operators.
4. **Nearby activity.** These are state wells whose status matches the config's `active_status`
   patterns. They are active *wells*, not lease boundaries. For actual federal lease polygons,
   add BLM data as a further layer.

Open issues to settle before publishing:

- **Operator names are only loosely normalized.** Subsidiaries and renamed companies count
  separately, so check any "top operator" claim against state filings before printing it.
- **"Last operator" is not "responsible party."** Many orphaned wells passed through bankrupt
  or dissolved companies, and liability depends on state law.
- **The USGS ownership fields are estimates.** USGS says its surface/mineral ownership comes
  from land-ownership maps and isn't official.
- **A state counts as checked** only after its operators are compared against a second agency source
  (see the table above). New states start unchecked.
